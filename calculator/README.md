# حاسبة ضريبة القيمة المضافة (VAT Calculator)

تطبيق ويب حاسبة بزرّين للضريبة، يعمل على الجوال والكمبيوتر، ويمكن تثبيته كتطبيق (PWA) ويعمل بدون إنترنت بعد أول فتح.

## الأزرار
| الزر | المعادلة | مثال (15%) |
|---|---|---|
| **+ ضريبة** | المبلغ × (1 + النسبة) | 1,000 ← 1,150 |
| **− ضريبة** | المبلغ ÷ (1 + النسبة) — استخراج الضريبة من مبلغ شامل | 1,150 ← 1,000 |

بعد الضغط يظهر تفصيل: المبلغ قبل الضريبة / مبلغ الضريبة / الإجمالي.

- النسبة الافتراضية 15% وقابلة للتعديل (تُحفظ تلقائياً).
- العمليات تُحتسب بأولوية رياضية صحيحة (100 + 50 × 2 = 200).
- الضريبة تُقرّب لهللتين (2 decimal).
- سجل لآخر 50 عملية؛ الضغط على أي سطر يعيد استخدام نتيجته.
- اختصارات لوحة المفاتيح: الأرقام والعمليات، `Enter` = ، `Esc` مسح، `T` + ضريبة، `R` − ضريبة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشره على GitHub Pages ثم من الجوال: "إضافة إلى الشاشة الرئيسية".
